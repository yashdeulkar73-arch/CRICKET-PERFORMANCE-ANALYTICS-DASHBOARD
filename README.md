# CRICKET-PERFORMANCE-ANALYTICS-DASHBOARD


## 📌 Project Overview

This project is an interactive **Cricket Performance Analytics Dashboard** created using Microsoft Excel. It transforms cricket performance data into an easy-to-understand dashboard for exploring player, team, venue, batting, and bowling performance.

## 🎯 Project Objective

The main objective is to analyze cricket performance data and present meaningful insights through interactive Excel dashboards, charts, Pivot Tables, and filters.

## 🛠️ Tools & Excel Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers / Interactive Filters
- Excel formulas and data analysis
- Data cleaning and organization
- Dashboard design
- KPI cards and visualizations

## 📊 Dashboard Highlights

The dashboard provides analysis of:

- Total Matches
- Total Players
- Total Runs
- Total Wickets
- Top 10 Run Scorers
- Top 10 Wicket Takers
- Team-wise performance
- Venue-wise analysis
- Batting Style analysis
- Bowling Style analysis

## 🔎 Key Insights

The interactive dashboard can be used to identify:

- Highest run-scoring players
- Leading wicket takers
- Team performance patterns
- Venue-based performance trends
- Distribution of batting styles
- Distribution of bowling styles
- Player and team performance using interactive filters
